# Fuye Cafe

A modern cafe website built with Vite, React, TypeScript, Tailwind CSS, and React Router.

## Overview

Fuye Cafe is a stylish landing page and event registration platform for a professional cooking class theme.  
It includes a landing page, events page, and a custom registration form with validation.

## Tech Stack

- Vite
- React
- TypeScript
- Tailwind CSS
- React Router
- Lucide React

## Features

- Responsive landing page with cafe branding.
- Events page for workshop and class promotions.
- Cooking class registration form.
- Built-in and custom validation.
- Uncontrolled form inputs.
- Success message auto-hide after submit.
- Clean component-based structure.

## Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/your-username/fuyecafe.id.git
cd fuyecafe.id
```

### 2. Install dependencies
```bash
npm install
```

### 3. Run development server
```bash
npm run dev
```

### 4. Build for production
```bash
npm run build
```

### 5. Preview production build
```bash
npm run preview
```

## Contribution Guide

We welcome contributions from developers of all levels.

### How to contribute

1. Fork the repository.
2. Clone your fork locally.
3. Create a new branch for your feature or fix.
4. Make your changes.
5. Test your code.
6. Submit a pull request.

### Branch naming examples

- `feat/register-validation`
- `fix/navbar-mobile-menu`
- `docs/readme-update`

### Pull request rules

- Keep changes focused.
- Write clear commit messages.
- Make sure the app runs without errors.
- Follow the existing code style.

For more details, see [CONTRIBUTING.md](./CONTRIBUTING.md).

## Code Style

- Use TypeScript for components and logic.
- Use Tailwind CSS for styling.
- Keep components reusable.
